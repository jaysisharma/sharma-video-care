# Design System

## Brand
Business: Sharma Video Care.

Existing direction:
- Black.
- Off-white.
- Restrained orange.
- Avoid excessive icons.
- Professional electronics/service-company feel.
- Prior messaging:
  - **Quality Products. Reliable Service.**
  - **Fixing Cameras, Saving Memories.**

## UX principles
- Clear before clever.
- Service-first actions must be obvious.
- Avoid clutter.
- Use strong typography and whitespace.
- Use icons sparingly.
- Make status and next action obvious.
- Forms should be short and progressive.
- Mobile responsive.
- Accessible contrast and keyboard navigation.

## Design tokens
Final exact primary/secondary hex values are a pending brand decision unless the existing brand files establish them.

Components:
- Header/navigation.
- Hero.
- Service cards.
- Product cards.
- Used-product cards.
- Request form.
- Quote card.
- Status timeline.
- Chat UI.
- Upload component.
- Checkout.
- Admin data tables.
- Technician job card.
- Toast/notification.
- Empty/error/loading states.

## Content rule
Use plain language. Avoid technical jargon unless useful to the customer.
