# User Flows

## Flow 1 — Repair
Home → Services → Category → Problem → Details → Upload photos/video → Location → Submit → Admin review → Inspection → Diagnosis → Quote → Customer accepts → Technician/job → Completion → Review.

## Flow 2 — Custom service
Home → Custom Service → Describe job → Upload evidence → Location → Submit → Review → Quote/inspection → Approval → Assignment → Completion.

## Flow 3 — Product purchase
Home → Shop → Search/filter → Product → Cart → Checkout → Address → COD/bank transfer → Order confirmation → Processing → Dispatch → Delivery.

## Flow 4 — Source product
Home → Request Something → Product details → Submit → Admin sources → Quote → Customer accepts → Order → Delivery.

## Flow 5 — Used product
Used → Product → Condition/disclosure → Cart → Checkout → Payment → Delivery → Review.

## Flow 6 — Technician
Assigned job → Review → Contact/chat → Visit → Inspection → Diagnosis → Parts/labour → Update → Complete → Admin verification → Customer notified.

## Flow 7 — Chat
Customer → Context (service/order/product) → Conversation → Messages/attachments → Staff response → Notifications → Conversation closed when resolved.

## Flow 8 — Bank transfer
Checkout → Bank transfer instructions → Customer uploads proof/reference → Pending verification → Admin verifies → Order confirmed → Fulfilment.
